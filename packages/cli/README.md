# arquitecto-mcp (bundle)

Empaqueta el servidor MCP de arquitecto-mcp en un solo archivo, `dist/main.mjs`, junto con el editor web compilado y las fuentes.

- Se compila con `pnpm build:cli` desde la raíz del repo.
- El paquete es `private`: no se publica en npm. Se ejecuta con su ruta local, sin `npx`.

Ver el [`README.md`](../../README.md) de la raíz. Licencia MIT; ver [`LICENSE`](../../LICENSE).
