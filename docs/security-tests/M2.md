# M2 — Path traversal en el slug de variantes

**Hallazgo de la auditoría (media):** se lee cualquier `.json` vía MCP y vía HTTP `/plan?variant=` y `/so-sanh?a=`. Evidencia en el upstream: `store.ts:234`, `live.ts:277-283, 311`.

**Causa raíz:** todos los llamadores (`live.ts` `/plan` y `/so-sanh`, `tools.ts` `variant_compare`, `store.openVariant`) pasan por `store.readVariant(slug)`, que hacía `path.join(variantsDir, `${slug}.json`)` sin validar.
